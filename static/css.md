### **CSS Files**

1.  **`css/doctor.css`**
    *   Styles for doctor-specific pages and dashboards.
        
    *   Customizes layout, tables, forms, buttons, and interactive elements related to doctor actions.
        
    *   Applied to doctor routes like `/doctor`.
        
2.  **`css/patient.css`**
    *   Styles for patient-specific pages.
        
    *   Manages layout, patient profile forms, dashboards, and visualization elements.
        
    *   Ensures a patient-friendly UI experience.
        
3.  **`css/admin.css`**
    *   Styles for admin pages and dashboards.
        
    *   Likely includes tables, forms, statistics panels, and user management interfaces.
        
    *   Applied to admin routes like `/admin`.
        
4.  **`css/login.css`**
    *   Styles the login page.
        
    *   Includes form input styles, buttons, and layout for authentication pages.
        
5.  **`css/notification.css`**
    *   Styles notifications (alerts, toasts, banners) across the application.
        
    *   Can be used by both doctors, patients, and admins.
